# H11: Flask project
Vytvořte nějaký netriviální projekt ve frameworku Flask (dle vlastního výběru):
  * **Demonstrace samotné aplikace proběhne osobně, buďto na 12. a 13. semináři, nebo v konzultačních hodinách (případně v jiný čas po domluvě).**
  * Zdrojový kód před demonstrací nahrajte do svého git repozitáře. 
  * Projekt by měl být Vaším vlastním dílem (ne stažený z webu nebo napsaný AI).
  * Příklady pro insipiraci: kalkulačka, aplikace na poznámky/upomínky, předvodníky jednotek atd.

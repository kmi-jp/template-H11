# H11: Flask project
Vytvořte nějaký netriviální projekt ve frameworku Flask (dle vlastního výběru):
  * Projekt by měl být Vaším vlastním dílem (ne stažený z webu nebo napsaný AI).
  * Aplikace by měla mít alespoň dvě stránky, v případě nutnosti perzistence dat stačí lokální soubory. 
  * Příklady pro insipiraci: databáze shlédnutých filmů s hodnocením, jednoduchá databáze pokemonů atd.
